# Chatbot

A simple and interactive chatbot web application that allows users to communicate with a bot through a clean, user-friendly interface. The project explores interactive UI development and message handling to create a smooth conversational experience.

## Features

- Interactive chat interface
- Send and display messages dynamically
- Real-time conversation updates within the interface
- Clean and responsive design
- User-friendly experience

## Technologies Used

- HTML
- CSS
- JavaScript

### Prerequisites

A modern web browser is all you need to run this project.
